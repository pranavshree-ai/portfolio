# Pranav Jadhav — Production Machine Learning & LLMOps Portfolio

An ultra-premium, interactive portfolio showcasing production machine learning, LLMOps pipelines, vector search architectures, and automated evaluation frameworks.

Built with **Zero Tailwind CSS**, leveraging pure vanilla CSS, modern reactive physics, and high-performance 60/120fps hardware-accelerated animations.

---

## 🌟 Key Architecture & Interactive Modules

- **Hero & 3D Magnolia Flower Scrub**: 198-frame sequential 3D lotus bloom smoothly synchronized with Lenis smooth scroll and atmospheric depth.
- **Impact & Precision 3D Orbit Cards**: Real-time rotating cylindrical orbit telemetry showcasing latency budgets, vector scale retrieval, and LLMOps evaluation metrics.
- **Autonomous Case Studies (5-Panel Split Card)**: Scroll-driven 5-panel split, 3D perspective flip, and card reveal.
- **Production AI Systems 3D Flip Stack**: Fluid card flip stack highlighting enterprise RAG, automated evaluation, and distributed inference engines.
- **Interactive Production Physics Toolkit (Matter.js)**: 120fps 2D physics arena featuring 29 production tools with grab, throw, zero-g blast, and category filtering.
- **3D Interactive Deck FAQ Orbit Stack**: Fan-out card deck with arrow navigation and architecture breakdowns.
- **macOS-Style Magnetic Dock**: Spring physics navigation dock with active section tracking and iOS safe-area support.
- **Decoupled Admin CMS (`/admin`)**: Dedicated administrative console to manage portfolio content, copy, telemetry, and live dark/light porcelain themes.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, GSAP 3 & ScrollTrigger, Lenis Smooth Scroll, Framer Motion, Matter.js, Lucide Icons.
- **Styling**: Pure Modular Vanilla CSS (Strictly Zero Tailwind CSS).
- **Backend CMS**: Node.js & Express API with file-based persistence and offline fallback.
- **Microservices**: Java 21 / Spring Boot portfolio backend.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pranavshree-ai/portfolio.git
   cd portfolio
   ```

2. **Start the Frontend Application**:
   ```bash
   npm --prefix frontend install
   npm --prefix frontend run dev
   ```
   The client will launch at `http://localhost:5175/`.

3. **Start the Express API Server (Optional - for CMS sync)**:
   ```bash
   npm --prefix server install
   node server/server.js
   ```
   The API will listen at `http://localhost:5001/`.

---

## 🔐 Administrative Console

Navigate to `http://localhost:5175/admin` (or press `Ctrl + Shift + A`) to access the dedicated Admin CMS.
